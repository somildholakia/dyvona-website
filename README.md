# Dyvona

Digital product studio building useful web utilities, ambitious software projects, and cross-platform apps.

## Website

Responsive React/Vite landing site for [dyvona.in](https://dyvona.in), with three product areas: utilities, major projects, and apps in development.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

Deploy on Vercel with build command `npm run build` and output directory `dist`. Add `dyvona.in` and `www.dyvona.in` in Vercel Domains, then configure the DNS records Vercel provides at GoDaddy.

## SEO

Includes page metadata, canonical URL, robots.txt, sitemap.xml, and an SVG favicon. Update social preview image and verify structured data before launch.
