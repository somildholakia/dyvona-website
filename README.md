# Dyvona

Dyvona is an independent software studio focused on designing and building useful websites, web applications, and MVPs.

## What we build

- **Websites:** responsive landing pages, portfolios, and multi-page business websites.
- **Web applications:** full-stack experiences, dashboards, user flows, and database-backed tools.
- **MVPs and custom software:** focused first versions that validate a workflow before it grows in complexity.
- **Product iteration:** testing, refining, and extending existing web products within an agreed scope.

We confirm requirements, deliverables, dependencies, pricing, and timeline before development begins. Listed website prices are indicative starting prices; final quotes depend on scope and complexity. Hosting, domains, paid APIs, and ongoing support are agreed separately.

- [Orbital PDF Studio](https://orbital-pdf-studio.vercel.app/) — browser-based PDF workflows.
- [Orbital Document Studio](https://orbital-document-studio.vercel.app/) — local-first document editing and export.

## Website

Responsive React/Vite landing site for [dyvona.in](https://dyvona.in/).

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

Deploy to Vercel with build command `npm run build` and output directory `dist`. The custom domain is configured through Vercel and the registrar's DNS settings.

## SEO

The site includes page metadata, a canonical URL, robots.txt, sitemap.xml, and structured organization data. Keep metadata aligned with current software-development services and verify it whenever the positioning changes.
